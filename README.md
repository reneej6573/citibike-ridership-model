# citibike-ridership-model
Tlab III: Building the Ridership Dataset (SQL)

Building and modeling a daily NYC Citi Bike ridership dataset joined with NOAA weather data (BigQuery + Python).

## Repository structure
- `code/` — analysis notebooks: EDA, preprocessing, modeling (Part 2)
- `data/` — the exported modeling dataset (`citibike_weather_daily.csv`)
- `queries/` — the SQL that builds the dataset (`build_dataset.sql`)
- `docs/` — data dictionary and supporting notes
